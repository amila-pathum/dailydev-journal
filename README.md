# DailyDev Journal

An automated developer inspiration journal.

## Features

- Daily quotes using ZenQuotes API
- Python automation
- JSON data storage
- GitHub Actions CI/CD
- GitHub Pages hosting

## Technologies

- Python
- HTML, CSS, JavaScript
- GitHub Actions
- GitHub Pages
- ZenQuotes API

## Automation

The GitHub Actions workflow runs every day
at 00:05 Sri Lanka time.

It fetches a quote, updates JSON data,
commits changes and deploys the website.
